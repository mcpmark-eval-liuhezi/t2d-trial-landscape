# T2D Trial Landscape

This repository contains the Type 2 diabetes trial landscape brief: aggregate ClinicalTrials.gov registry statistics by trial phase, overall recruitment status, and sponsor class; profiles of the three largest currently recruiting, industry-sponsored T2D trials by enrollment; and the SUNSHINE (NCT01608724) citation check.

It is published from ClinicalTrials.gov registry data as `landscape.md` on the `report` branch via pull request into `main`.
