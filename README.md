# T2D Trial Landscape

This repository publishes the Type 2 diabetes trial landscape brief as `landscape.md` on the `report` branch via pull request into `main`.

Aggregate phase, recruitment status, and sponsor class statistics from ClinicalTrials.gov; profiles of the three largest recruiting, industry-sponsored T2D trials by enrollment; and the SUNSHINE (NCT01608724) citation check.

## What this repo contains

- `landscape.md` on the `report` branch: the full T2D trial landscape brief (phase, status, and sponsor-class counts; three largest recruiting industry-sponsored trials by enrollment; SUNSHINE citation check).
- This README on `main`: repository overview and a two-line description of the repo contents.

Data sourced from the ClinicalTrials.gov public registry (condition: type 2 diabetes). Counts as of 2026-11-02.
