# T2D Trial Landscape

Type 2 diabetes clinical trial landscape brief from ClinicalTrials.gov.

## What this repo contains

- `landscape.md` on the `report` branch: the full T2D trial landscape brief (aggregate counts by phase, overall recruitment status, and sponsor class; three largest recruiting industry-sponsored trials by enrollment; SUNSHINE citation check for NCT01608724).
- This README on `main`: repository overview and a two-line description of the repo contents.

Two-line description: The `report` branch carries `landscape.md` with the T2D trial landscape brief (phase, status, and sponsor-class counts; top recruiting industry-sponsored trials by enrollment; and the SUNSHINE citation check). `main` holds this README and the README update lands here via the pull request from `report`.

Data sourced from the ClinicalTrials.gov public registry (condition: type 2 diabetes). Counts as of 2026-11-02.
