# T2D Trial Landscape

This repository contains the diabetes group's type 2 diabetes trial-landscape materials: `landscape.md`, the full quarterly-review brief covering ClinicalTrials.gov registry aggregates (trials by phase, by recruitment status, and by sponsor class), the three largest recruiting industry-sponsored trials, and the SUNSHINE (NCT01608724) citation check.
Supporting files are `anchor.txt`, the anchor trial's registry-verified facts, and `report.md`, an earlier date-scoped draft whose figures are superseded by those in `landscape.md`.

Collection for the diabetes group's sponsor-review trial-landscape brief.

The collection is anchored on a single reference trial:

- **Anchor trial registry number:** NCT01608724 (SUNSHINE, saxagliptin 5 mg in type 2 diabetes; lead sponsor AstraZeneca; overall status COMPLETED; actual enrollment 2,165)

Contents:

- `anchor.txt` — the anchor trial's registry-verified facts (NCT ID, acronym, lead sponsor, overall status).

Derived figures used in the brief:

- **Enrollment total (first ten currently recruiting Phase 3 type 2 diabetes trials):** 20,902
- **Enrollment median (same ten trials):** 915

The anchor trial's enrollment (2,165) is 1,250 above (about 2.37x) that median.

Source: ClinicalTrials.gov (registry data retrieved live for this brief).
