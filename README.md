# T2D Trial Landscape

This repository holds the type 2 diabetes clinical-trial landscape brief for the quarterly portfolio review — registry aggregate statistics by phase, recruitment status, and sponsor class; the three largest currently recruiting industry-sponsored trials; and a citation check on the SUNSHINE saxagliptin trial (NCT01608724).

All figures are drawn live from the ClinicalTrials.gov public registry and recorded in `landscape.md` on the `report` branch.
